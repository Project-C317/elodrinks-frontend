## 🔸 Sobre o Frontend

O frontend do EloDrinks oferece uma **experiência visual moderna, fluida e responsiva**, permitindo que usuários explorem serviços, montem orçamentos e acompanhem informações personalizadas. Também contempla uma interface administrativa com recursos para gerenciamento de serviços e itens opcionais.

Usuários podem simular pacotes de serviços para festas, selecionar serviços adicionais e finalizar solicitações. Já os administradores acessam um painel de controle exclusivo, com funcionalidades voltadas à manutenção do catálogo e gestão da plataforma.

## 🔸 Como Executar Localmente

Siga os passos abaixo para rodar o projeto localmente em sua máquina:

1. **Clone o repositório**
```bash
git clone https://github.com/Project-C317/elodrinks-frontend.git
```

2. **Acesse a pasta do projeto**
```bash
cd elodrinks-frontend
```

3. **Instale as dependências**
```bash
npm install
```

4. **Execute a aplicação**
```bash
npm run dev
```

> Acesse `http://localhost:5173` no navegador para visualizar o projeto.
